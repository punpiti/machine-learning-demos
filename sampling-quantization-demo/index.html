Sampling & Quantization — เห็นข้อมูลที่หายไปจริง ๆ

Sampling = ลดจำนวนตำแหน่งที่เก็บค่า, Quantization = ลดจำนวนระดับค่าที่เก็บได้ต่อตำแหน่ง — ทั้งสองอย่างทำให้ภาพขยับกลับมาขนาดเดิมได้ แต่ข้อมูลจริงที่เหลืออยู่น้อยลง ด้านล่างจะเห็นทั้งขนาดจริง (เล็กลงจริง ๆ) และขนาดที่ขยายกลับมาให้ดู (บล็อก ๆ) พร้อมตัวเลขปริมาณข้อมูลที่หายไป

Sampling คือการเลือกตำแหน่งพิกเซลบนกริดที่ห่างขึ้น แล้วทิ้งพิกเซลระหว่างนั้นไปทั้งหมด ไม่ใช่การเบลอ/เฉลี่ย — เป็น "จุดสุ่มตัวอย่าง" ตามทฤษฎีจริง ๆ

ภาพที่ "ขยายกลับ" ให้ใหญ่เท่าเดิม (บล็อกสี่เหลี่ยม) กับภาพ "ขนาดจริง" ที่เล็กลง — มีข้อมูลเท่ากันทุกประการ การขยายกลับไม่ได้เพิ่มข้อมูลใหม่ แค่ทำซ้ำพิกเซลเดิมเพื่อแสดงผล

ถ้าตัวอย่าง (sample) ห่างเกินไปเทียบกับความถี่ของลวดลายในภาพ จะเกิด Aliasing — ลองเลือกพรีเซ็ต "แถบความถี่ (Nyquist)" แล้วเพิ่ม block size ดูว่าจุดที่ลายเริ่ม "บิดเบี้ยวผิดรูป" ขยับซ้ายมาเรื่อย ๆ

Nyquist limit ของการสุ่มทุก N พิกเซล คือความถี่สูงสุด 1/(2N) รอบ/พิกเซล ที่ยังไม่ alias — ตัวเลขนี้อัปเดตสดตามสไลเดอร์ block size ด้านล่าง

Quantization ลดจำนวนระดับความเข้ม/สีต่อพิกเซล — bit ยิ่งน้อย เห็นแถบขั้นบันได (posterization) ชัดขึ้น ปริมาณข้อมูลต่อพิกเซลก็ลดตามจำนวน bit ตรง ๆ
